# Metroid Fusion 대사 조판 편집기

프로젝트 루트의 `start_dialogue_editor.cmd`를 실행하면 기본 SSOT인
`workspace/text/review/metroid_fusion_translation_ko_english_controlcodes_fixed.csv`를 연다.
CSV 또는 기존 `entries[].ko` 형식 JSON도 `열기`로 불러올 수 있다.

## 사용법

1. 왼쪽 목록이나 검색으로 대사를 선택한다.
2. 오른쪽 한국어 번역문에서 커서를 원하는 위치에 둔다.
3. `줄바꿈`, `페이지`, `종료` 버튼이나 `색상 코드`, `배치 코드`, `화자·연출`,
   `상태 코드`, `특수 글리프` 메뉴로 제어문을 삽입한다.
4. `사용 코드 전체...`는 불러온 번역문에 실제 들어 있는 코드와 사용 횟수만 보여 준다.
5. 아래 프리뷰의 페이지, 넘침 경고, `현재 페이지 제어 순서`를 확인한다.
6. `Ctrl+S`로 저장한다. 기존 파일은 저장 전에 `backups/dialogue_editor`에 복사된다.

Enter 키는 실제 개행 문자가 아니라 게임의 `{br}` 토큰을 삽입한다. 프리뷰는 원본 ROM의
영문 글리프와 `Galmuri11-Condensed_9x12.png` 한글 비트맵을 사용한다. `{ctrl:FD00}`은
페이지 전환으로 처리한다. `8100~8106` 색상 계열은 글자색, `80xx` 배치 계열은
출력 좌표, 특수 글리프는 ROM 글리프로 프리뷰에 반영된다. 화자·연출·게임 상태처럼
문자로 그려지지 않는 제어도 무시하지 않고 프리뷰 아래의 실행 순서에 모두 표시한다.
편집기는 임의 16진수 제어 입력을 허용하지 않으며, 현재 불러온 번역문에서 집계된 코드만
삽입할 수 있다.
빨간 프레임은 한 페이지가 3줄을 넘거나 한 줄이 대화창의 216px 유효 폭을 넘었다는 뜻이다.

프리뷰 통과는 실제 게임 실행 검증을 대신하지 않는다. 저장 후 빌드하고 Mesen에서 해당 장면의
대사 진행, 페이지 전환, 이벤트 타이밍을 확인해야 한다.
