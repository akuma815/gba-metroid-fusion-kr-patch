# Metroid Fusion 실플레이 QA 무적·무한 미사일 스크립트

대상 ROM은 `build/metroid_fusion_ko_v48_translation_update_qa.gba`이다. ROM 자체를
수정하지 않으며 Mesen 2 실행 중 현재 에너지 감소와 현재 미사일 감소 쓰기만 차단한다.

1. Mesen에서 v48 ROM을 실행하고 게임플레이까지 진행한다.
2. `Debug` → `Script Window`를 연다.
3. `workspace/tests/cheat_invincible.lua`를 열고 `F5`로 실행한다.
4. 우측 상단에 `QA INV`가 표시되면 무적이, `M숫자`가 함께 표시되면 무한 미사일이 적용된 상태다.
5. 중지하려면 Script Window에서 스크립트를 정지하거나 창을 닫는다.

검증된 일본판 IWRAM 구조는 현재 에너지 `0x03001344`, 최대 에너지
`0x03001346`이다. 스크립트는 정상 에너지 값이 60프레임 유지된 뒤에만 활성화되어
부팅·메뉴 초기화 값을 건드리지 않는다. 일반 피격과 환경 피해로 에너지가 감소하지
않으며, 일부 스크립트 공격의 넉백·피격 동작은 그대로 발생할 수 있다.

현재/최대 미사일은 `0x03001348`/`0x0300134A`다. 무적 활성화 뒤 미사일을 획득하고
현재 미사일이 1발 이상인 상태가 60프레임 유지되면 무한 미사일도 활성화된다.
현재 미사일 감소 쓰기만 최대치로 치환하므로 최대치 증가, 아이템 획득과 세이브
데이터는 막지 않는다. 미사일을 모두 소진한 뒤 스크립트를 켠 경우에는 리차지 룸이나
미사일 보급으로 최소 1발을 회복해야 활성화된다.

이 스크립트를 켠 실행은 번역 표시·진행 QA용이다. 전투 밸런스, 피해량, 사망 처리,
엔딩 통계 검증에는 사용하지 않는다.

## v32 즉사 결함 수정

v31 스크립트는 쓰기 콜백이 돌려준 CPU 형식 주소를 IWRAM 상대 주소로 다시 읽을 수 있었다. 이 경우 0을 읽어 피격 쓰기값을 0으로 바꾸므로 한 대만 맞아도 즉사했다. v32 스크립트는 콜백 주소를 다시 읽지 않고, 활성화 시 저장한 체력의 하위·상위 바이트를 직접 반환한다.

현재 대상은 `build/metroid_fusion_ko_v48_translation_update_qa.gba`이며 실행 도우미는 `start_mesen_v48_qa.cmd`다. 정적 회귀 검사는 통과했고 실제 적 피격·미사일 사용 수동 확인은 사용자 플레이 QA가 남아 있다.
